# 😃 Emotion Detection with Deep Learning

This project is an emotion detection system that classifies human facial expressions into categories like **happy**, **sad**, **angry**, **surprised**, and more — all using deep learning and computer vision!

leverage the [FER 2013 Emotion Detection dataset](https://www.kaggle.com/datasets/ananthu017/emotion-detection-fer/data) from Kaggle to train and evaluate the model.

---

## 💡 Overview

In this project, we:
- Preprocess and augment facial image data
- Build a CNN (Convolutional Neural Network) to classify emotions
- Evaluate performance using accuracy and loss metrics
- Visualize predictions on test images

---

## 🛠 Tech Stack

- **Python** 🐍
- **TensorFlow / Keras** 🧠
- **OpenCV** 📸
- **NumPy, Pandas, Matplotlib** 📊

---

## 📦 Dataset

 Used the [FER 2013 Emotion Detection dataset](https://www.kaggle.com/datasets/ananthu017/emotion-detection-fer/data), which contains:
- 35,887 grayscale facial images (48x48 pixels)
- Labeled across 7 emotion categories: `angry`, `disgust`, `fear`, `happy`, `sad`, `surprise`, `neutral`
